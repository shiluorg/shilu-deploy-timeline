Original entry and sentence-level review

Around 1750 BCE the text of the Code of Hammurabi was carved.1 It gathers nearly 280 judicial decisions and is not a code in the modern sense.2 Placing “Code of Hammurabi” in 1760 BCE Asia, it connects earlier and later change in Politics.3 For readers, the significance of “Code of Hammurabi” is best read through its connections with the events around it.4

Around 1750 BCE, the text of the Code of Hammurabi was engraved.5 It compiles nearly 280 judicial decisions and is not a code in the modern sense.5 Putting the "Code of Hammurabi" back to Mesopotamia in 1760 BCE, it connects the changes in politics over a long period of time.6 For readers, the meaning of "The Code of Hammurabi" must be understood from its connection with subsequent events.7
